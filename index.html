What is Devil's Witness?

Digital evidence passes through multiple hands — police, forensic labs, investigators, lawyers, courts. Each transfer becomes a record. Each file receives a cryptographic fingerprint. If anything changes, everyone knows instantly.

Evidence Integrity

Records a cryptographic fingerprint for each file without storing the file itself.

Immutable Audit Trail

Every custody change is recorded, timestamped, and auditable by authorized parties.

Chain of Custody

Ensure accountability from collection to courtroom with verified transfers and status history.

Instant Verification

Upload a file and confirm whether the evidence has been altered in seconds.

Evidence Vault

Add evidence records. Files are hashed locally; only fingerprints and metadata are retained. Editing any block changes its hash and marks all subsequent blocks INVALID.
